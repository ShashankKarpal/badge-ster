# Pull Shark

Awarded for merged pull requests you authored.

## Tiers

| Tier | Merged PRs |
| --- | --- |
| Base | 2 |
| Bronze (x2) | 16 |
| Silver (x3) | 128 |
| Gold (x4) | 1024 |

## Notes

- Only merged PRs count. Closed-without-merge does not.
- PRs in your own repos count. Private repos count if private contributions are enabled in profile settings.
- This is the badge that quietly rewards a branch-and-PR workflow over committing straight to main.

Source: community-maintained criteria list (Schweinepriester/github-profile-achievements), checked 2026-08-25.
