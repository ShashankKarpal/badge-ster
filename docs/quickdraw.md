# Quickdraw

Awarded for closing an issue or pull request within 5 minutes of opening it.

## Notes

- One qualifying close is enough. No tiers.
- Opening and closing your own issue counts.
- The issue that earned this badge lives in this repo and was closed in seconds.

Source: community-maintained criteria list (Schweinepriester/github-profile-achievements), checked 2026-08-25.
