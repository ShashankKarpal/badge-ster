# Pair Extraordinaire

Awarded for a coauthored commit in a merged pull request.

## Tiers

| Tier | Coauthored merged PRs |
| --- | --- |
| Base | 1 |
| Bronze (x2) | 10 |
| Silver (x3) | 24 |
| Gold (x4) | 48 |

## Correction, tested live in this repo

The co-author in the trailer must be a real GitHub account. A trailer pointing at an email with no account behind it (first attempt: an AI assistant's noreply address) did not trigger the badge. This commit is co-authored with a real user via their GitHub noreply address, which is the corrected test. The badge counts for both the PR author and the co-author.

## Notes

- The commit needs a `Co-authored-by: Name <email>` trailer, separated from the message body by a blank line, and the PR must be merged.
- Use the co-author's GitHub noreply address (ID+username@users.noreply.github.com) so the commit links to their account.

Sources: community-maintained criteria list plus live test in this repo; checked 2026-08-27.
