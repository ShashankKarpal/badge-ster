# Pair Extraordinaire

Awarded for a coauthored commit in a merged pull request.

## Tiers

| Tier | Coauthored merged PRs |
| --- | --- |
| Base | 1 |
| Bronze (x2) | 10 |
| Silver (x3) | 24 |
| Gold (x4) | 48 |

## Notes

- The commit needs a `Co-authored-by: Name <email>` trailer, separated from the message body by a blank line, and the PR must be merged.
- Whether the coauthor email must belong to a real GitHub account is not officially documented. The commit carrying this file is the experiment.

Source: community-maintained criteria list (Schweinepriester/github-profile-achievements), checked 2026-08-25.
