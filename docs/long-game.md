# The long game

The achievements no scratch repo can give you.

## Starstruck

16 stars on a single repo you created (128 for Bronze, 512 Silver, 4096 Gold). Needs a project other people actually want. Ship, post, repeat.

## Galaxy Brain

2 accepted answers in GitHub Discussions (8 Bronze, 16 Silver, 32 Gold). Answer real questions in repos with Discussions enabled; the author has to mark your answer as accepted.

## Public Sponsor

Sponsor any open source developer via GitHub Sponsors. Any amount, one time works.

## Retired or unattainable

Arctic Code Vault Contributor (2020 snapshot), Mars 2020 Contributor (mission repos), Heart On Your Sleeve and Open Sourcerer (disabled), Proxima badges (GitHub staff only).

Source: community-maintained criteria list (Schweinepriester/github-profile-achievements), checked 2026-08-25.
